# Movie Library App (Module Pattern)

## Features
- Search movies via OMDb API
- View movie details in modal
- Add/remove favorites
- Save favorites in localStorage

## Technologies
- HTML, CSS, JavaScript
- Fetch API (async/await)

## Design Pattern
- Module Pattern (encapsulation & separation of concerns)

## Setup
1. Get API key: https://www.omdbapi.com/apikey.aspx
2. Replace in app.js:
   const API_KEY = "YOUR_API_KEY";
3. Open index.html
